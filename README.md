# GabrielOS

Plataforma de agências, agentes de IA, Bank e integrações. Status: fase de proposta e provas técnicas. Não há código de produto ainda.

## Estrutura
- `docs/desenho-plataforma.md`: desenho consolidado (módulos, departamentos, decisões, pendências).
- `docs/provas/provas-tecnicas.md`: plano das provas P1 a P6 com critérios de aceite.
- `docs/decisoes/`: registros de decisão (um arquivo por decisão, com alternativas e consequências).
- `scripts/`: verificações técnicas. Nunca imprimem segredos.

## Segredos
Chaves e segredos ficam fora do repositório, no cofre do OpenBot. Nada de chave em arquivo versionado.
